# 公式与符号国标速查表

依据：GB 3102.11—93《物理科学和技术中使用的数学符号》、GB 3100～3102—93《量和单位》、GB/T 15834—2011《标点符号用法》，以及出版社《作译者指南》（2020）第二部分“数学符号与公式须知”“公式”“字母与角标”。表中“确定”指规范明文，确认语义后可直接写给作者。**作者习惯、全书一致用另一种写法，都不是豁免理由**：全书统一写错的，照样作为确认问题逐处列出，并在首页注明“全书统一问题，共 N 处”。只有已核实、适用于当前对象的专门国标条文（如 GB/T 3505 的评定长度 ln）才可作例外，并记录标准号和条款。

## 一、正体（直立）

| 对象 | 规范写法 | 常见错误 | 级别 |
|---|---|---|---|
| 函数名、运算符 | sin x、cos x、tan x、cot x、sec x、csc x、arcsin x、sinh x、ln x、lg x、log_a x、exp x、lim、max、min、sup、inf、det A、grad、div、rot、sgn、arg | 斜体 *sin*；与自变量连写 sinx；首字母大写 Sin、Max | 确定 |
| 反三角函数 | arcsin x、arccos x、arctan x、arccot x | sin⁻¹x、tg、ctg、arctg、arcctg | 确定 |
| 常用对数 | lg x（以10为底）、ln x（以e为底） | log x 表示以10为底（未注明底数） | 确定 |
| 圆周率 | π（正体） | 斜体 π | 确定 |
| 自然对数的底 | e（正体），如 e^x、exp x | 斜体 e | 确定（先确认是常数 e，变量 e、电子电荷 e 另判） |
| 微分号 | dx、dy/dx、d(…)、∬…dxdy 中的 d（正体）；偏微分号 ∂ | 斜体 d | 确定（先确认是微分算子，距离、直径等变量 d 斜体） |
| 虚数单位 | i（正体），如 e^{iωt}、a+ib | 斜体 i | 确定（先确认是虚数单位，求和指标、序号 i 斜体） |
| 计量单位 | m、s、kg、Pa、m/s、kg·m⁻³（正体，与数值之间空半格） | 斜体单位；9m/s 连写 | 确定 |
| 说明性上下标 | x_max、C_g（g 指气体）、E_r（r 指相对） | 斜体 max、g、r | 确定 |
| 数字 | 0～9 一律正体 | 斜体数字 | 确定（注意 PDF 导出可能换字体造成假象，以 docx 属性为准） |

## 二、斜体与粗斜体

| 对象 | 规范写法 | 级别 |
|---|---|---|
| 变量、函数符号 | *x*、*y*、*f*(*x*)、*g*、*a*ₙ | 确定 |
| 表示变量、坐标、连续数的下标 | *a*ᵢ、*p*ₓ（x 指 x 轴）、*a*ₙ（n 为连续数） | 确定 |
| 几何点、线、面 | 点 *A*、线段 *AB*、△*ABC* | 确定 |
| 向量、矩阵、张量 | 粗斜体 ***a***、***A***；转置 ***A***ᵀ（T 正体） | 确定 |
| 物理量 | *v*、*t*、*m*、*U*、*R*；不用多字母作量符号（MTTF→*t*_MTTF；特征数 Re 等除外） | 确定 |

## 三、符号写法

| 对象 | 规范 | 常见错误 | 级别 |
|---|---|---|---|
| 导数撇号 | *f*′(*x*)、*y*″（U+2032 ′、U+2033 ″） | 英文单引号 '、中文引号 ’ | 确定（docx 中为 ' 时先看 PDF 是否显示为撇号） |
| 增量 | Δ*x*（希腊字母 Δ） | 三角形 △；Δ 与 ∆（U+2206）混用 | 确定 |
| 不等号 | ≤、≥，全书一种 | ≤ 与 ⩽ 混用；=<、>= | 确定 |
| 省略号 | 数学中用 ⋯（居中）或 …，全书一种；*x*₁, *x*₂, ⋯, *x*ₙ | 中文“……”用于公式；三个句点 ... | 确定 |
| 乘号 | 数与数 3×5；量的乘积 *UI* 或 *U*·*I*；矢量积 ***a***×***b***；数量积 ***a***·***b*** | 用星号 * 作乘号（卷积除外）；×与·随意混用 | 确定 |
| 夹在正文中的分数 | *x* = 1/(3*y*) | 竖式分数挤在行内 | 建议 |
| 数值范围 | 10%～30%、(4～20)×10⁻³、−40～+85 ℃ | 10～30%、4～20×10⁻³ | 确定 |
| 偏差 | (20±4) ℃、220×(1±10%) V | 20±4 ℃ | 确定 |
| 约数 | 约 8、8 左右（二选一） | 约 8～10 左右 | 确定 |

## 四、公式编排

| 对象 | 规范 | 级别 |
|---|---|---|
| 编号 | 按章编号（1-1）或（1.1），全书一种；置于公式行最右侧；编号前不加“式”字 | 确定 |
| 引用 | 正文写“式（1-1）”“式（2-1）～式（2-4）” | 确定 |
| 转行 | 在 =、+、−、×、÷ 等符号处转行，上下行尽量在 = 处对齐；运算符不出现在行首（按社内体例） | 确定 |
| 式中注释 | “式中 *L*——电感（H）；”或“式中，*L* 为电感（H）；”二选一，全书统一 | 确定 |
| 公式编辑器 | 全书统一一种（Word 公式或 MathType），字体字号一致 | 建议 |
| 函数输入 | Word 公式中用“函数”结构输入 sin、ln 等，可自动正体并留空，不要逐字母敲入 | 给作者的操作建议 |
