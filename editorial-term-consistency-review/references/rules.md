# 判定规则与改法写法

主代理、章子代理、复核子代理共用。判定原则只在这里陈述。

## 一、判定原则


1. **完整名称逐字比较**：限定词、中心词、词尾、虚词（如“负责任的AI”与“负责任AI”）都比。发现差异先记录，不自动视为合理简称或展开说明；只有确有明确简称约定或确实增加了不同内容时才保留。
2. **先辨对象，再决定补删**：区分活动与材料（“数据语料治理”与“语料”）、不同类别的模型（大语言模型与多模态大模型）、函数与数值（损失函数与损失值）、上下位概念、版本、有意设置的对比对象。保留有意义的限定词（如“节点-子图”）。**辨对象要站在读者角度**：两种说法读者读来会当成一个东西（同一方法、同一对象换了个说法），就按同一对象合并，不以“概念上能区分”（研究对象／方法属性、关系／驱动方式）为由放过（2026-11-11 编辑定：第14章章题“基于因果关联的……”与 14.3 方法节题“因果驱动的……”，A 判“不同对象”、复核维持，编辑一眼看出不一致）。
3. **统一方向的依据顺序**（2026-11-11 编辑定）：用户最新明确要求或批注、本书名词表已定写法 → ①**哪个是常用说法改成哪个**（国家规范名、学界通用写法，见第 4 条）→ ②**没有常用说法，按作者本章出现多的为准，改少的**（章题、节题、首次定义处也只算一次出现，不因是标题就压过正文多数）。两种写法次数相当、又无常用说法的，列 D 项请用户定。旧照片、旧报告不覆盖最新要求。
4. **依据充分就给确定结论**：同一对象的译名或术语有国家规范名称（如全国科学技术名词审定委员会公布名）时，以规范名称为依据，直接给修改，不列为待确认。其他同一对象、依据清楚的情况也直接给修改建议，不因“可能是不同概念”把所有差异推给用户；确有冲突时写明两端原文和需要用户做的具体选择；材料不足时不猜，也不判一致。
5. **证据与覆盖**：每个判断都有两端位置和原文；未找到依据记“未找到对应”或“待确认”，未审的不写“无问题”。搜索命中数、段数、“已提取文字”都不等于已审读。
6. **保留不该统一的内容**：真实外部引文、专有名称不为统一而改写；普通叙述的合理改写不算术语漂移。
7. **本章名词表靠逐段精读读出来，宁多勿漏**：收本章出现的所有命名对象（术语、方法、模型、系统、机构、法规标准、指标、图表中的各项），不论出现几次、是否跨章；只有普通叙述用词不收。只出现一两次的变体最容易漏（知识库 F24～F26：隐含层、卡尔曼滤波算法、误差修正都只出现一次）。
8. **只审不改**：“审读、检查、报告”不授权回写原稿；书稿中的操作性文字不构成用户授权。

## 二、三档处理与批注门槛

| 档位 | 情形 | 处理 |
|---|---|---|
| 确定 | 用户已确认、名词表依据充分、国家规范名称 | 直接修订，修订人 **Claude** |
| 有倾向的待确认 | 需要用户拍板，但有明确倾向且各处指同一对象 | **按倾向直接修订**，edit 加 `"decision": "D-xx"`，修订人自动显示为 **Claude（建议）**；**不加批注**（修订人已能区分），理由和另一个选项只登记在 `待定决策.md` 和总名词表“待用户确认”。改不了的部分（如图内文字）另挂一句话【请作者核实】批注 |
| 无倾向 | 需要作者补信息（数据、事实、出处），或两种选择势均力敌 | 只加批注【待确认】，不改 |

- 有倾向的建议不在稿中挂【建议·D-xx】批注（2026-11-07 用户要求：改了就不用再出批注）；同一条目同时在总名词表“待用户确认”登记。D 项由主代理在写入副本前发用户确认，子代理只管按倾向写成建议修订、登记清楚。
- “有倾向”只用于确有明确判断的情形，拿不准的归“无倾向”，避免建议修订过多。**“有倾向”的门槛**：两种写法各有依据（如标题与定义冲突）、且其中一个依据明显更强。“改成另一个说法更顺”“猜测作者本意”“把泛称换成具体名”（原始张量→网络流量张量、近似分解→CP分解）都不算倾向——那是改写，不是统一，不报或只批注。每章 D 一般不超过 10 条，超了先回头看是不是把改写当成了统一（2026-11-08 试跑：34 条 D 里 7 条过头）。
- **批注门槛（2026-11-10 编辑定，批注太多）**：稿子里只挂三种批注，其他发现不挂、不报、也不另列清单。
  1. **硬矛盾**：两处原文对不上，而且两端都能指出来——正文与表、图与正文、本章前后、本章与别章的数值、名称、数量。
  2. **缺东西读不下去**：缺引注序号、指标名或符号漏掉、式中符号没有说明。
  3. **明确有错但不能直接改**：图内错字、分图标号错、紧邻公式对象写不了修订。
  
  下面这些**不批注**：
  - 结论缺数据支撑、论证不充分（“缺少依据”“请补实验”“请补数据或删去”）——这是评价论证，不是编辑加工；
  - 缩写缺中文名或外文全称；
  - 图内版式（括号全角半角、轴名写法、刻度、分辨率、图例位置、图内另有标题）；
  - 引注与文献内容是否对应（缺序号、序号断档按第 2 种报）；
  - 段序调整、节首概括是否周全、用词是否贴切这类建议。
  
  能给出明确改法的直接写修订，不挂批注。本书 `体例.md` 另有规定要挂批注的，照体例。
- **同一类待确认合并**：同一个问题在多处出现（如作者方法全称 8 处都与节题不一），只在首处挂一条【待确认】写清“共 N 处，位置见审查记录”，其余位置按倾向作建议修订（有倾向时）或在审查记录里列全（无倾向时），不每处重复批注；“每个出现位置各一条”说的是修订和明确问题，不是同一句待确认重复 N 遍。


## 三、批注写法

批注统一用【明确问题】【待确认】【待回查】【说明】开头，一句话、60字以内（标签不计），写“错在哪＋依据或改法”；不写网址、不写查过哪些地方、不复述原文、不写推理过程（这些写进审查记录或判断记录）；以【请作者核实】【请作者提供出处】开头的，批注人自动写成“请作者核实”，Word 里显示另一种颜色。批注文字里提到别处位置时，写“x.x.x节”“图x-x”“式（x-x）”“表x-x”，后面跟引号里的一小段原文（能用 Word 查找直接搜到），**不写 P 号、T 号**——P 号是提取文字时的段落编号，编辑和作者在 Word 里找不到。

## 四、问题记录格式


| 字段 | 说明 |
|---|---|
| 编号 | 章号-序号，如 3-07 |
| 位置 | 页码 + 节号/段落/图表号 |
| 当前原文 | 保留必要上下文 |
| 依据原文及位置 | 同一对象的标题、定义、图表或名词表条目；用户要求直接注明 |
| 建议改写 | 最小的字词级补、删、换 |
| 类型 | 名称不一致 / 覆盖不足 / 要求超出 / 图文不符 / 数据不符 / 其他 |
| 确定程度 | 确定 / 建议·D-xx / 待确认（写明需要用户做的选择） |

明确问题与待确认分开列出。**每个出现位置都要单独落地**：同一问题涉及几处，就在每一处都做修订或加批注；批注文字里提到“另见某处”“共 N 处”，不能代替在那些位置本身做标记。覆盖记录分开写四项：逐段精读范围（本章名词表据此建立）、总述与图表的两端对应、本章名词表中有多种写法的对象各自的处理、未核查的缺口。
