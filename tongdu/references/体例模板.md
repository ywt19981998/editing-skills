# 《书名》体例表

编辑已定的写法。通读按此判断：符合体例的不报；不符合的直接改（同类在第一处写说明），不再出【待确认】问体例。新书开始前请编辑把“待定”一栏逐项定下来。

| 项目 | 体例 | 定于 |
|---|---|---|
| 数值与单位符号之间 | 待定：空一格（国标，如“3 km”）／不空格（如“3km”） | |
| 中文单位名与符号 | 待定：带数字时一律用符号（10min、1h）／允许中文（10分钟） | |
| 计数用数字形式 | 待定：十以内用汉字（三个）／一律阿拉伯数字（3个）；统计表和带单位的数值都用阿拉伯数字 | |
| 多位数分节 | 待定：三位空四分之一字（科技书常用，如“45 000”）／不分节／千分撇 | |
| 表内数值记法 | 待定：很小的数用科学记数（“9.56×10⁻⁷”，指数上标；如小于0.001时）／一律小数（定小数位数）；不用程序输出式“9.56e-07” | |
| 同一张表各分块格式 | 同一表内各分块（如两个数据集、两组实验）表头对齐、数值记法、小数位数或有效数字一致 | |
| 非法定单位 | 公里→千米（或 km），公斤→千克（或 kg） | |
| “式中”后的标点 | 待定：“式中，”／“式中：” | |
| 式下符号说明版式 | 待定：接排一段“式中，X为……；Y为……。”／分行“X——……；” （全书一致；引出语不用“其中”；动词统一“为”） | |
| 中文与外文、数字之间 | 待定：不空格／空一格 | |
| 外国作者署名 | 待定：只写姓（“Rahman等”）／照原文 | |
| 外国地名、人名译名 | 待定：以规范译名为准（如“得克萨斯州”）／从俗 | |
| “以及”前的逗号 | 三项及以上顿号列举、末项用“以及”时加逗号（A、B、C，以及D）；两项不加 | |
| 比较符号 | 用标准“<”“>”“≤”“≥”，不用全角“＜”“＞” | |
| 破折号 | “——”占两个字位 | |
| 正文用颜色指认图中要素 | 待定：彩印保留／黑白印要改／后期二维码，不改只登记 | |
| 项目报告用语（“本项目”“团队”） | 待定：改为“某项目”／暂不改不报 | |
